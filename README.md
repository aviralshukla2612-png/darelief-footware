# DARELIEF WALKWEAR — Luxury Women's Footwear

A high-end editorial e-commerce web application for **Darelief Walkwear**, featuring dual-density orthotic comfort technology, interactive 3D footwear models, seamless shopping cart, simulated checkout, order tracking, and comprehensive policy portals.

## 🌟 Key Features

- **Luxury Art Direction**: Ivory (`#FAF7F2`), Deep Maroon (`#701A2B`), and Soft Gold accents with Playfair Display serif typography.
- **Interactive 3D Studio Configurator**: Three.js WebGL footwear model with real-time 360° rotation, color material switching, and multi-angle camera perspectives.
- **Editorial Auto-Advancing Hero**: Dynamic fashion slideshow with product tags and direct CTA navigation.
- **Full Catalog & Filtering**:
  - Filter by Category, Size (IND/UK), Color variants, and Price range.
  - Multi-category routing (`/new-arrivals`, `/flats`, `/sandals`, `/heels`, `/office-wear`, `/comfort`).
- **Product Experience**:
  - High-res image gallery, 3D model view toggle, size guide modal, pincode delivery checker, and customer reviews.
- **Complete Shopping Flow**:
  - Local storage-persisted Cart and Wishlist.
  - Dynamic coupon validation (`WELCOME10`, `URBAN20`) and free shipping threshold meter.
  - 4-stage simulated checkout flow with address selection, payment methods, and celebratory confetti order confirmation.
- **Customer Account & Tracking**:
  - Profile management, saved addresses, interactive order timeline, and doorstep return/exchange submission.
- **Brand & Legal Portals**:
  - Craftsmanship hallmarks, customer service cards, and centralized policies hub (`/policies`, `/shipping-policy`, `/return-exchange`, `/cancellation-policy`, `/refund-policy`, `/privacy-policy`, `/terms`, `/payment-policy`).

## 🛠️ Technology Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **UI & Styling**: React 19, Tailwind CSS 4, Vanilla CSS Design System
- **3D Graphics**: [Three.js](https://threejs.org/) (WebGL Canvas & Shaders)
- **Icons & Effects**: [Lucide React](https://lucide.dev/), Canvas Confetti
- **Typography**: Google Fonts (*Playfair Display* & *Outfit*)

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
